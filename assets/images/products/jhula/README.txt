Put the Jhula photos in this folder.

Name them like this (the number is the order they appear in):
    jhula 1.jpg
    jhula 2.jpg
    jhula 3.jpg   ... and so on

- Any photo format works: jpg, jpeg, png, webp, avif, gif, bmp, heic ...
- Use lowercase names with a space before the number.
- To replace a photo, upload a new one with the SAME name.
- Photos of any shape (tall, wide, square) are fine - nothing gets cropped.
- Slots without a photo stay hidden. To allow more photos than the
  current slots, raise the numbers in  assets/js/collections.js
